## Inline Question 3:
Which of these data preprocessing steps is analogous to batch normalization, and which is analogous to layer normalization?

1. Scaling each image in the dataset, so that the RGB channels for each row of pixels within an image sums up to 1.
2. Scaling each image in the dataset, so that the RGB channels for all pixels within an image sums up to 1.  
3. Subtracting the mean image of the dataset from each image in the dataset.
4. Setting all RGB values to either 0 or 1 depending on a given threshold.

## Answer:
[FILL THIS IN]

Batch normalization:

(3) Subtracting the mean image of the dataset from each image in the dataset.

This is analogous because batch normalization normalizes across the batch (dataset-level statistics) for each feature/channel.


Layer normalization:

(2) Scaling each image so that the RGB channels for all pixels within an image sum to 1.

This is analogous because layer normalization normalizes within each individual sample, using statistics computed from that sample only.


## Inline Question 4:
When is layer normalization likely to not work well, and why?

1. Using it in a very deep network
2. Having a very small dimension of features
3. Having a high regularization term


## Answer:
[FILL THIS IN]

Correct choice: 2. Having a very small dimension of features

Layer normalization computes mean and variance across the feature dimension for each individual sample. If the number of features is very small, these statistics become unreliable and noisy, leading to poor normalization and unstable training.
